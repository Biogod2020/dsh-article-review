# DSH 0.2 适配与使用体验

2026-10-03 · 插件 `0.2.0-rc.1` · DSH `0.2.0-rc.2`（上游 `639ed015`）· macOS / arm64。

结论：阅读、批注、模型修稿、接受/拒绝、换图、文献和记录恢复已跑通。README 保持短文案，增加 PDF、换图、文献与窄屏截图。

## 槽点与本次修复

| 原问题 | 改动 |
|---|---|
| 进度轨和说明抢正文空间 | 改为固定工具栏中的小进度按钮，按需展开目录 |
| 窄侧栏只剩图标，难猜用途 | 保留简短文字，统一按钮间距、圆角和选中状态 |
| 选文件先弹宿主 Finder，远程使用别扭 | 稿件、BibTeX、图片统一默认浏览工作区；Finder 单独入口 |
| 引用跳转误显示“修改位置 / 返回变更” | 显示引用定位并返回文献页 |
| 换图哈希被误判为论文数字变化 | 数字检查排除文件路径和引用键，保留正文数值的原文位置 |
| 模型没批注也必须传空数组 | `paper_propose.annotationIds` 可省略，默认空列表 |
| 类别标签无法解释具体风险 | 按类别/需要判断筛选，显示精确变化证据 |
| `paper_check` 与真正接受的检查不一致 | 共用接受预检：版本、锁、引用、图快照和大小 |
| 全文工具一次输出太多 | 按完整区块分页，续页固定版本，避免截断可编辑原文 |
| 更新后 NativeCommandRunner 调用缺参数 | 显式传入最新接口要求的可见执行模式 |
| 文件不存在时露出长系统路径 | 简短错误显示所请求的稿件路径 |

## 实际操作

| 功能 | 结果 |
|---|---|
| 文件选择 | 工作区、嵌套目录、直接路径、无效路径；退出后重新打开 |
| 选区与批注 | 黄色高亮、下划线、重复短语第二处定位；移除/恢复、复制、专注阅读；批注解决/重开、批量附到输入框 |
| 草稿和进度 | 草稿刷新恢复/丢弃；已审、锁定/解锁、目录展开/收起与跳转 |
| 修改提案 | 真实模型创建及原位重写；过滤/空状态、渲染/源码差异、正文定位、接受与拒绝 |
| 版本和历史 | 两版本选择、交换、渲染并排、源码并排/行内；接受后基线保持旧版本 |
| 图片与 PDF | 预览、全屏、缩放、100%、适应、拖动、切图、缺图重试、DSH 独立 PDF 标签页；换图拒绝/接受及前后快照 |
| 文献 | 浏览/路径绑定、过滤/空状态、解绑/重绑、作者年份显示、引用定位 |
| 外部编辑与恢复 | 当前阅读版本保持；显式载入新版本；丢失锚点记录归档、恢复、重新关联 |
| 视觉 | 英文/中文、深色/浅色、默认窗口及 360px/430px 窄屏；工具栏不遮正文，窄屏对比上下排列 |

真实 Muse Spark 1.3 共完成三轮功能请求，覆盖全部 17 个稿件工具。第三轮完成 BibTeX 查找/绑定/列举/读取/新增/替换，插入后接受、删除后拒绝、换图后拒绝。模型曾漏传 `annotationIds`，重试成功；上表记录了对应接口修复。首次模型启动因隔离环境缺凭据失败，补齐该测试环境配置后完成三轮。所有稿件、数字和书目均为虚构测试材料。

## 验证与仍需改进的地方

- 完整集成：31 个测试文件、215 项通过；宿主和客户端严格类型检查通过。
- 便携测试：12 个文件、67 项通过；独立核心类型检查通过。
- 编译后的 tarball 在全新 DSH Web 配置中安装、启动并读取已有审阅记录成功；发布 tag 携带同一编译产物和注册表依赖。
- 上游源码构建遇到 `micromark-util-types` 2.0.2/2.0.3 类型冲突；只在隔离的 DSH 测试副本中统一为 2.0.3。

macOS 原生选择器已通过参数、取消和路径边界测试；本次视觉自动化没有完成系统文件窗口的选择操作。Windows 的便携核心测试不等于完整桌面验证，宿主锁仍需 `koffi`。历史版本目前用于对比，恢复正文仍需手动复制；大历史尚无裁剪。这三处适合下一轮集中改进。
